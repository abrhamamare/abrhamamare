# Abrham Getachew Amare

**Cybersecurity Engineer | PhD Researcher in Computer Engineering | 5G Security & Post-Quantum Cryptography**

I'm a cybersecurity researcher and engineer interested in turning security research into practical, testable systems. I am currently pursuing a PhD in Computer Engineering at **Université de Sherbrooke**, studying how ontologies of cryptographic requirements can support organizational **crypto-agility** and migration to **post-quantum cryptography (PQC)**.
